# Radhakrishna Panchadhatu

A modern jewellery storefront scaffold designed for admin-controlled product, pricing, image, and content updates.

## Features

- Public storefront shell
- Admin dashboard structure
- Product/category/order/settings screens
- CMS-ready data model and placeholders
- No hardcoded storefront product data for launch

## Getting started

```bash
npm install
npm run dev
```

Then open http://localhost:3000

## Notes

This project is intentionally structured so product photos, prices, stock, category labels, banners, and business details are added later from admin screens rather than from source files.
